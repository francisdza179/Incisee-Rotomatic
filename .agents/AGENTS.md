# Incisee Rotomatic Project Rules

- **Use the Template System**: Before modifying headers, footers, or layout structures in individual HTML files, always check the `templates/` folder.
- **Do not manually edit compiled sections**: Always edit the template files (`templates/header.html`, `templates/footer.html`) and run `node compile_pages.js` to regenerate the HTML files, rather than editing individual HTML files directly.
